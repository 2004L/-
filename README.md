# Hotel Agent OS

AI 无人酒店开源原型。当前版本提供可交互的入住任务控制台，用于演示 AI 如何围绕 `checkin_case_id` 持续处理身份读取、公安登记、支付、分房和发卡。

## 架构边界

- 前端控制台显示 AI 决策、门店节点和审计时间线。
- 后续核心服务应拆分为 AI Agent Runtime、入住状态机、公安浏览器 Worker、PMS 适配器、支付适配器和 Windows 设备服务。
- 广州与珠海使用独立公安浏览器会话、任务队列和本地身份数据区。
- 身份证实际字段不进入 AI 上下文；AI 使用短期 token 和业务状态作出决策。
- 首期自助终端采用语音前台：负责 TTS 语音、文字状态提示、触屏引导与异常解释；不使用人物形象、口型或云端视频生成。它不直接持有身份证字段、公安浏览器权限、支付权限或发卡权限。

## 首期业务范围

首期只处理成年人持有效中国居民身份证的正常入住。未成年人、境外客人、特殊证件、身份证损坏或证件不符，均进入可扩展的人工接管队列，不阻塞核心正常入住链路。

## AI 跨部门协同

AI 通过统一通知接口把不能由终端自行恢复的事项推送给对应部门：

- 支付争议、客诉和复杂账务：财务或客户关系部门。
- 房态异常：前台和保洁部门。
- 门锁、发卡机和房间设备故障：工程部门。
- 客人退房：自动创建保洁任务，传递房号、退房时间和清洁优先级。
- 公安页面验证码、系统维护、证书异常：前台与安全岗一次性处理。

建议统一事件契约：

```json
{
  "case_id": "CI-20260913-0087",
  "department": "工程部",
  "task_type": "door_lock_fault",
  "priority": "high",
  "payload_token": "opaque_token",
  "reason": "门锁写卡失败",
  "source": "ai_orchestrator"
}
```

## 本地运行

```bash
pnpm dev
```

在控制台顶栏点击“查看语音终端”，可体验首版语音前台状态：欢迎、读证、核验中、人工协助。后续若需要升级数字人，可复用独立的语音状态与文本协议，再增加口型或形象渲染层；触屏操作始终保留为无障碍与降级通道。
